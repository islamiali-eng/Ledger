# دفتر تراکنش‌ها (نسخه نصب‌شدنی)

یک برنامه PWA فارسی برای ثبت درآمد و هزینه، مانده حساب بانک‌ها و گزارش‌گیری. روی گوشی مثل یک اپ نصب می‌شود و بعد از بار اول بدون اینترنت هم باز می‌شود.

## فایل‌ها

- `index.html`: خود برنامه (همه‌چیز در همین یک فایل است)
- `manifest.webmanifest`: نام و آیکن برنامه برای نصب
- `sw.js`: باز شدن بدون اینترنت
- `icon-192.png`، `icon-512.png`، `icon-maskable-512.png`، `apple-touch-icon.png`: آیکن‌ها

## مرحله ۱: آپلود روی یک میزبان HTTPS

نصب‌شدنی بودن فقط روی آدرس `https://` کار می‌کند. باز کردن مستقیم فایل `index.html` از حافظه گوشی نصب نمی‌دهد. هر میزبان ایستا کافی است، مثلاً:

- Netlify: وارد netlify.com/drop شوید و کل پوشه را روی صفحه بکشید و رها کنید.
- Cloudflare Pages یا GitHub Pages: پوشه را به‌عنوان یک پروژه ایستا آپلود کنید.

هر پنج فایل باید کنار هم و در یک پوشه باشند.

## مرحله ۲: نصب روی گوشی

- **آیفون (Safari):** دکمه Share، سپس Add to Home Screen.
- **اندروید (Chrome):** منوی سه‌نقطه، سپس Install app یا Add to Home screen.

## داده‌ها

- تراکنش‌ها و مانده‌ها فقط روی همان دستگاه و همان مرورگر ذخیره می‌شوند و به جایی ارسال نمی‌شوند.
- با پاک کردن داده‌های مرورگر یا حذف اپ، اطلاعات از بین می‌رود. به همین دلیل در تب «گزارش» دکمه «پشتیبان‌گیری» هست. گاهی یک فایل پشتیبان بگیرید و برای انتقال به گوشی دیگر از «بازیابی از پشتیبان» استفاده کنید.
- داده روی دو دستگاه به‌صورت خودکار همگام نمی‌شود.

## به‌روزرسانی

اگر فایل‌ها را عوض کردید، عدد `CACHE` را در `sw.js` تغییر دهید (مثلاً `ledger-v2`) و دوباره آپلود کنید تا گوشی‌ها نسخه جدید را بگیرند.
